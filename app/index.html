🚀 Zero to Prod na OCI

Demonstração prática de uma esteira de CI/CD de ponta a ponta, integrando containers, IaC e automação na Oracle Cloud.

Sobre o Projeto

Olá! Meu nome é Alison Melo. Esta página foi provisionada e configurada 100% via código.

O objetivo deste laboratório é demonstrar a entrega automatizada de software, aplicando as melhores práticas de DevOps. Desde o commit no repositório até o servidor online, não houve intervenção manual.

🧰 Stack Tecnológico

Docker GitHub Actions GitHub Container Registry Terraform Ansible Oracle Cloud (OCI) Linux (Ubuntu)

⚙️ A Esteira de Automação (CI/CD)

1

CI (Build & Push)

O código-fonte e o Dockerfile são analisados pelo GitHub Actions. A imagem da aplicação é construída e enviada com segurança para o registro do GitHub (GHCR).

2

IaC (Provisionamento)

A pipeline aciona o Terraform, que se autentica na Oracle Cloud e provisiona a infraestrutura base: Virtual Cloud Network, Subnets, regras de Firewall e a máquina virtual (Compute Instance).

3

Configuration Management

Com a máquina no ar, o Ansible assume o controle via SSH. Ele atualiza os pacotes do sistema operacional, instala o motor do Docker e prepara o ambiente para receber a aplicação.

4

Deploy

Por fim, a imagem Docker mais recente é baixada do registro na nuvem e o container é executado, expondo a aplicação na porta web padrão. O ciclo se completa com sucesso!
