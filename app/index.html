DevOps Portfolio Project

Olá, meu nome é Alison Melo. Bem-vindo! Esta página é a vitrine de um projeto que demonstra um pipeline CI/CD End-to-End totalmente automatizado, focado em Infrastructure as Code (IaC) na Oracle Cloud.

Para acessar o código-fonte (Terraform, Ansible e Docker), visite o repositório oficial:
[github.com/alison-melo/devops-portfolio-project](https://github.com/alison-melo/devops-portfolio-project)

Git Push

O gatilho do ciclo. Todo código é versionado e auditado.

Terraform

Provisionamento automático de rede e VM na Oracle Cloud.

Ansible

Configuração do S.O, Firewall e instalação do Runtime.

Docker

Deploy da aplicação em container isolado e portável.

CI/CD Pipeline

  • GitHub Actions orquestrando o deploy contínuo.
  • Segurança via SSH Secrets (id_rsa).
  • Pipeline automatizado do push ao ambiente de prod.

Cloud Infrastructure

  • Oracle Cloud (OCI) - Ashburn Region.
  • Instância AMD VM.Standard.E2.1.Micro.
  • Rede isolada via VCN e Security Lists.

OS Hardening

  • Configuração automatizada de IPTables via Ansible.
  • Ambiente imutável via Docker Nginx-Alpine.
  • Gestão de acesso via chaves SSH autorizadas.
HCL / Terraform YAML / Ansible Docker Engine Linux / Ubuntu Oracle Cloud
